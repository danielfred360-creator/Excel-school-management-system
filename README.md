# 📚 Excel School Management System

## 📖 Overview

This project is an automated School Management System built with Microsoft Excel and VBA.

It helps schools automate student registration, payment tracking, attendance management, and reporting.

---

## 🚀 Features

- Student Registration
- Automatic Student ID Generation
- Payment Tracking
- Attendance Management
- Attendance Calendar Generator
- Dashboard Reporting
- Summary Statistics
- VBA Automation
- Data Validation
- Error Handling

---

## 🛠 Tools Used

- Microsoft Excel
- Excel VBA
- XLOOKUP
- Excel Tables
- Conditional Formatting
- Data Validation
